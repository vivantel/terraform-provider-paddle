## Fact

This provider's `docs/` (the Terraform Registry-facing docs — schema
reference pages, distinct from this repo's `docs/{facts,decisions,...}/`
knowledge-artifact directory) are generated by HashiCorp's `tfplugindocs`
tool from resource/data-source schema descriptions plus any
`templates/`/`examples/` content, rather than hand-written. CI runs
`tfplugindocs generate` and fails the build if it produces a diff against
what's committed, so registry docs can never silently drift from the actual
schema.

This was a low-friction call during the [[0001-existing-provider-baseline]]
roadmap interview — `tfplugindocs` is the de facto standard for
registry-published providers, and the Terraform Registry actually requires
this `docs/` layout to render provider documentation pages at all, so there
was no real alternative worth treating as a full decision record.
